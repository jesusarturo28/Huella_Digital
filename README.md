# Huella Digital

Agencia de páginas web, branding y automatización para negocios.

Este repositorio contiene el sitio web de Huella Digital y los archivos de marca.

## Estructura

| Ruta | Contenido |
|---|---|
| `index.html` | Página principal (servicios, paquetes, proceso, preguntas frecuentes y contacto) |
| `styles.css` | Estilos del sitio |
| `script.js` | Menú en celular |
| `assets/img/` | Logos optimizados para la web (blanco y negro con fondo transparente), ícono e imagen para redes |
| `marca/` | Logos originales |
| `docs/Paquetes_HuellaDigital.pdf` | Hoja de paquetes y precios |

## Publicar con GitHub Pages

El sitio es HTML, CSS y JavaScript sin compilación.

1. En GitHub, abre **Settings → Pages**.
2. En **Source**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda. En unos minutos el sitio queda en `https://jesusarturo28.github.io/Huella_Digital/`.
